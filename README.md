# Stille Helden

Kleines Klassenspiel für den Unterricht: Ein Glücksrad zieht ein Tagesziel, im Hintergrund werden geheim stille Helden ausgelost. Wer das Ziel erreicht, bekommt Sterne und kann seinen Avatar im Shop gestalten.

Die App besteht aus einer einzigen Datei (`index.html`) und läuft im Browser. Spielstände werden nur im Browser des jeweiligen Geräts gespeichert (Einstellungen: Namen ändern, Sicherung kopieren oder einspielen).

## Auf dem iPad als Web-App

1. Seite in Safari öffnen.
2. Teilen-Symbol, dann **Zum Home-Bildschirm**.
